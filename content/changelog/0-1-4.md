Four tiers of plugin, each one PR. Tier zero is a manifest with no code, and the `changelog` plugin that declares this very page is it. Tier one checks the manifest and attributes every option to the file that set it. Tier two is slots and filters, declared in YAML and run in the order the `plugins:` list names, with a client budget that weighs what a plugin puts on the page. Tier three is stages and events: a transform runs on a copy, an emit goes through core, and a push reports what its plugins said. Tier four gives each plugin one tool, a prompt that names the order, and an explain that builds to find out.

With it, the settings schema: a theme declares what a site may choose, and the answer is checked before it is used. `autolink` and `indexnow` ship as bundled plugins; this site enables both.

Tag `v0.1.4` on the [repository](https://github.com/snymrova/snypd/releases/tag/v0.1.4). The npm publish waited on a credential; the host still built with 0.1.3 the week this was tagged, which is why the menus and the plugins on this site went live later than the tag.
